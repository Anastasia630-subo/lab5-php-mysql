ЗАПУСК В XAMPP
1. Распакуйте папку lab5_php_251-361 в C:\xampp\htdocs\
2. Запустите Apache и MySQL в XAMPP Control Panel.
3. Откройте http://localhost:8080/phpmyadmin/ (если Apache настроен на порт 8080).
4. Перейдите во вкладку «Импорт», выберите lab5_data.sql и нажмите «Вперёд».
   SQL-файл сам создаёт базу lab5_data, таблицу terms и 10 начальных записей.
5. Для стандартного XAMPP настройки db.php: localhost, root, пустой пароль.
   Если у MySQL настроен пароль, измените DB_PASSWORD в db.php.
6. Откройте http://localhost:8080/lab5_php_251-361/index.php
   При работе Apache на 80-м порту: http://localhost/lab5_php_251-361/

КАК УСТРОЕН ПРОЕКТ (3 PHP-ФАЙЛА)
- db.php — соединение с MySQL через mysqli + функция e() для безопасного вывода.
- index.php — SELECT из таблицы terms, таблица 10 терминов, галерея 10 изображений,
  форма добавления новой записи.
- add.php — обработка POST, проверка и загрузка изображения, INSERT в БД,
  возврат на главную страницу и сообщение об успехе (при ошибке — сообщение).
- lab5_data.sql — база данных и 10 начальных записей.
- assets/style.css — оформление.
- assets/img/*.svg — 10 иллюстраций, названия показаны при наведении (title).
- uploads/ — папка для новых изображений.

ПРОВЕРКА
На главной странице должно отображаться 10 терминов и 10 изображений.
Введите новый термин, определение и прикрепите PNG/JPG/WEBP до 2 МБ.
После отправки появится сообщение об успешном добавлении, а в таблице и галерее
появится новая запись. Обновление страницы не удаляет запись — она хранится в MySQL.

ПУБЛИКАЦИЯ НА PHP-ХОСТИНГЕ
1. Загрузите все файлы в папку сайта (например, htdocs).
2. В панели хостинга создайте базу данных и пользователя.
3. Импортируйте SQL: если хостинг не позволяет CREATE DATABASE, удалите первые
   две команды CREATE DATABASE и USE в файле SQL перед импортом в существующую БД.
4. В db.php укажите хост, имя пользователя, пароль и имя БД хостинга.
5. Проверьте, что сервер разрешает запись в папку uploads.
6. Не публикуйте секретный пароль базы данных в открытом GitHub-репозитории.
   Для публичного репозитория оставляйте только локальные учебные значения в db.php.

КОНТРОЛЬНЫЕ ВОПРОСЫ
1. MySQL — реляционная СУБД для хранения данных в таблицах.
2. PHP подключается к MySQL, выполняет SQL-запрос и выводит результат в HTML.
3. Ошибки соединения нужно проверять, чтобы не выполнять запросы без подключения.
4. Для соединения нужны хост, пользователь, пароль и имя базы.
5. Способы: mysqli (объектный или процедурный) и PDO.
6. DDL: CREATE/ALTER/DROP; DML: INSERT/UPDATE/DELETE; DQL: SELECT;
   DCL: GRANT/REVOKE; TCL: COMMIT/ROLLBACK.
7. К БД обращаются через mysqli или PDO, передавая SQL-запрос.
8. SELECT и fetch_assoc/fetch_all получают записи, PHP выводит их через цикл в HTML.
